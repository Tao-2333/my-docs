# Git 使用指南

本页面介绍 Git 的基本操作流程。

## 1. 创建本地仓库

如果希望使用 Git 管理一个项目，可以先进入项目目录，然后执行：

```bash
git init
```

该命令会初始化一个 Git 仓库，并创建用于保存版本信息的 `.git` 目录。

## 2. 查看文件状态

```bash
git status
```

该命令可以查看工作区和暂存区的状态，例如哪些文件已经修改、哪些文件等待提交。

## 3. 添加和提交文件

先将文件添加到暂存区：

```bash
git add README.md
```

然后创建一次提交：

```bash
git commit -m "更新项目说明"
```

我的理解是，`git add` 用于选择本次准备提交的内容，而 `git commit` 用于将暂存区的内容保存为一次版本记录。

## 4. 推送到远程仓库

当本地仓库已经关联 GitHub 远程仓库后，可以执行：

```bash
git push origin main
```

该命令将本地 `main` 分支的提交推送到远程仓库。

## 5. 常用工作流程

1. 修改本地文件。
2. 使用 `git status` 检查文件状态。
3. 使用 `git add` 将修改加入暂存区。
4. 使用 `git commit` 创建提交。
5. 使用 `git push` 将提交推送到 GitHub。

## 6. 我的学习体会

刚开始学习 Git 时，我容易混淆添加文件、提交版本和推送远程仓库这三个操作。

后来我逐渐理解，它们并不是同一个过程：添加文件是准备提交内容，提交是保存本地版本，推送则是将本地提交同步到远程仓库。
